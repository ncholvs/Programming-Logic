Debugging Exercise (Corrected):

// This pseudocode segment is intended to compute and display
// the cost of home ownership for any number of users
// The program ends when a user enters 0 for the mortgage payment
start
   Declarations
      num mortgagePayment
      num utilities
      num taxes
      num upkeep
      num total
   startUp()
   while mortgagePayment <> 0
      mainLoop()
   endwhile
   finishUp()
stop

startUp()
   output "Enter your mortgage payment or 0 to quit"
   input mortgagePayment
return

mainLoop()
   output "Enter utilities"
   input utilities
   output "Enter taxes"
   input taxes
   output "Enter amount for upkeep"
   input upkeep
   total = mortgagePayment + utilities + taxes + upkeep
   output "Total is ", total
   output "Enter your mortgage payment or 0 to quit"
   input mortgagePayment
return

finishUp()
   output "End of program"
return

Corrections Made:
1. Changed the call "startup()" to "startUp()" so it matches the module name exactly.
2. Changed the call "MainLoop()" to "mainLoop()" so it matches the module name exactly.
3. Changed "input mtgPayment" to "input mortgagePayment" in startUp(). The variable mtgPayment was never declared; the declared variable is mortgagePayment.
4. Added a prompt and "input mortgagePayment" at the end of mainLoop(). Without it, mortgagePayment never changes inside the loop, so the loop would run forever and the user could never enter 0 to quit.
5. Changed "not equal to" to "<>" for readability.

Test 1: mortgagePayment = 1000, utilities = 200, taxes = 150, upkeep = 100
total = 1000 + 200 + 150 + 100 = 1450
Output is "Total is 1450", then the user is asked for the next mortgage payment.

Test 2: mortgagePayment = 0
The loop ends, finishUp() runs, and the output is "End of program"
